The first word of the text is the mind map's centre — every path below it branches out from that centre. After that, each line is a branch path, split by "/" or "\". Lines sharing the same starting segments merge into the same branch. A segment starting with "http" is treated as a link: it becomes clickable and shows a thumbnail + page title instead of the raw URL. A segment starting with "folder:" (e.g. folder:C:\Users\My Documents) is treated as a local folder: clicking it copies the path to your clipboard so you can paste it into Explorer's address bar — browsers can't open Explorer directly. Adding "<text>" at the end of a line attaches the rest of that line as a hidden tooltip on the node just before it (e.g. RASR/Paper/<text>This is the detail of the paper shows that detail only when you hover over "Paper"). Drag to scroll, pinch or scroll-wheel to zoom. Click any branch node to make it the new centre and see only its sub-nodes, spaced out to fill the screen — use Back to return. Clicking a node with no sub-nodes shows its full text in a popup instead. "Crawl Google Drive" signs you into your Google account, then opens Google's own folder picker so you choose which folder to load — the mindmap is built from that folder's contents, with file thumbnails and click-to-open links, up to 400 items per scan (this turns on "Only show directories" automatically, since a full folder scan is usually busy). Files sitting right in the crawled folder (not inside any subfolder) are gathered under one small Files in Root link inside the centre circle, below the mindmap's title, instead of crowding the map with a branch per file — click it to open a table in the top-right showing each file's thumbnail, name (click to open it) and a notes column, shown as a white-on-black badge whenever a note exists (click to add or edit; no hovering needed to see it). Editing a note saves it straight back to Drive automatically — no separate save step. That table closes itself shortly after your mouse leaves it, or use its × button; its own "Save notes to Drive" button is there for a manual save too, if you want one. Crawling a folder saves a small cache file into it once finished, and crawling that same folder again offers to load the cache instantly instead of re-scanning from scratch — it remembers your notes but not thumbnails, since those are images rather than text, so a fresh scan re-fetches those. With lots of nodes, names that would overlap are hidden automatically and reappear as you zoom in; untick "Declutter labels" to force every name to draw at once. Hover any other node for a small menu: Centre makes it the new middle of the map (use Back to return), Move then lets you click another node to make the first one (and everything under it) a child of that node, + Node adds a child (plain text, a weblink, or a folder: path), − Node deletes it and everything under it, and <text> attaches hover text — the Files in Root link doesn't show this menu, since Centre/+Node etc. don't apply to it. Every edit is written straight back into this text box using the normal "/" and <text> separators. A bare link with no enclosing folder never shows a name, however far you zoom — only links inside a folder can reveal theirs. With "Only show directories" unticked, Drive image and PDF files show a thumbnail that grows (and gets sharper) as you zoom in, just like everything else on the map. Word, PowerPoint and Excel files (.docx/.doc/.pptx/.ppt/.xlsx/.xls) show Drive's own preview when it's reachable, and a plain coloured file-type badge when it isn't — browsers increasingly block the cookie that preview depends on, so the badge is there to guarantee something always shows. Hovering never shows the popup menu over a file that's currently hidden. "Save Local" / "Load Local" download or open this MindText as a .txt file; "Save Drive" writes it as a new timestamped file in your Google Drive, and "Load Drive" opens Google's picker so you can choose a .txt file to load.
